# EduConnect

Plateforme de mise en relation entre structures proposant des activités pédagogiques (intervenants) et structures souhaitant organiser une intervention (établissements, structures éducatives et périscolaires).

## État du projet

Le projet est en phase de **cadrage** : aucun code applicatif n'a encore été écrit. Le développement suit une méthode par phases documentées et validées une à une — voir [`docs/00-process.md`](docs/00-process.md).

- Phase en cours : **1 — Cadrage produit** ([`docs/01-cadrage-produit.md`](docs/01-cadrage-produit.md))
- Décisions validées : [`docs/DECISIONS.md`](docs/DECISIONS.md)
